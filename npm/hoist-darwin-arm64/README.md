# @keelstackhq/hoist-darwin-arm64

The hoist binary for macOS arm64. Installed by [`@keelstackhq/hoist`](https://www.npmjs.com/package/@keelstackhq/hoist)
as an optional dependency; do not depend on it directly.

```bash
npm install -g @keelstackhq/hoist
```
