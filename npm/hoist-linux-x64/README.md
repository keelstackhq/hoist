# @keelstackhq/hoist-linux-x64

The hoist binary for Linux x64 (static musl). Installed by [`@keelstackhq/hoist`](https://www.npmjs.com/package/@keelstackhq/hoist)
as an optional dependency; do not depend on it directly.

```bash
npm install -g @keelstackhq/hoist
```
